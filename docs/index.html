IntentCheck

A Rust CLI tool to verify SEO + AI-search consistency: Title / Meta / H1 vs Page Content.

What it does

IntentCheck checks whether a page communicates a consistent topic across its title, meta description, main heading, and body content. It helps catch mismatches, thin content, and unclear positioning before publishing.

Install & Run

cargo run -- analyze page.html
cargo run -- analyze site/ --top 3 --report-md report.md
cargo run -- analyze https://example.com --report-md url_report.md

Download

For now, download the source code from GitHub and run it locally.

Why it matters now

Search is changing fast: more people find content through AI assistants. Consistent, clear pages are easier to understand and recommend. IntentCheck helps validate that consistency.
