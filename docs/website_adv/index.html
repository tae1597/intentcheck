IntentCheck

A lightweight Rust CLI tool that validates whether your page structure truly matches its content.

View on GitHub Back to Main Site

Why It Matters

Modern search engines increasingly rely on AI-based semantic understanding. If your title says one thing but your content says another, your page can be misunderstood or ignored.

Core Features

Semantic Consistency Score

Scores alignment between Title, Meta description, H1 and Body.

Mismatch Detection

Identifies missing key terms and structural inconsistencies.

CI Integration

Use --fail-under to automatically block low-quality content.

Markdown Reports

Generate shareable reports for documentation and audits.

Example Commands

cargo run -- analyze page.html
cargo run -- analyze site/ --fail-under 60
cargo run -- analyze https://example.com --report-md report.md
