IntentCheck

A Rust CLI tool that verifies SEO and AI-search consistency between Title, Meta Description, H1 and Page Content.

Download on GitHub View Source Code

Why IntentCheck?

In the AI-search era, search engines and AI assistants evaluate content based on semantic clarity and internal consistency. Many websites publish pages where titles, meta descriptions and body content do not align.

IntentCheck detects these inconsistencies before publishing, helping developers and content creators improve clarity, credibility and discoverability.

Core Features

  • Semantic overlap scoring (Title / Meta / H1 vs Body)
  • Thin content detection
  • Folder-wide analysis for static sites
  • Outlier detection across pages
  • JSON & Markdown report export
  • CI-ready --fail-under quality gate

Example Usage

cargo run -- analyze page.html
cargo run -- analyze site/ --top 3 --report-md report.md
cargo run -- analyze https://example.com --fail-under 60
